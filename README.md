# FireEngineerAI — نظام إدارة مشاريع الحماية من الحريق

نسخة محدّثة من البرنامج بواجهة احترافية (Dark Mode) وميزات إدارية إضافية.

## ما الذي تغيّر عن النسخة السابقة؟

### الشكل (UI)
- ثيم داكن احترافي كامل (ألوان، بطاقات، أزرار، جداول) بدل التصميم الافتراضي لـ Qt.
- قائمة جانبية (Sidebar) بدل شريط الأدوات العلوي، مع تمييز الصفحة النشطة.
- لوحة معلومات (Dashboard) رئيسية: إحصائيات سريعة، توزيع المشاريع حسب الحالة،
  تنبيهات فحص المعدات القريبة/المتأخرة، والفواتير غير المسددة.
- شارات ملوّنة لحالة المشروع وحالة الفحص/الفواتير بدل نص عادي.

### الوظائف الجديدة
1. **جدول عملاء منفصل** — بدل حقل نصي حر، أصبح لكل عميل سجل مستقل (اسم، جهة
   اتصال، هاتف، بريد، عنوان) ويمكن ربط عدة مشاريع بنفس العميل.
2. **الفواتير** — إنشاء فواتير لكل مشروع مع مبلغ، تاريخ إصدار/استحقاق، وحالة
   (مسددة/غير مسددة)، مع تمييز الفواتير المتأخرة تلقائيًا.
3. **المعدات والفحص الدوري** — تسجيل معدات الحماية من الحريق لكل مشروع (طفايات،
   مضخات، لوحات إنذار...) مع تاريخ آخر فحص ودورة الفحص، ويحسب البرنامج تلقائيًا
   موعد الفحص القادم ويُصدر تنبيهًا عند الاقتراب أو التأخر.
4. **تقارير PDF احترافية** — بدل ملف txt، الآن يتم توليد تقرير PDF منسّق لكل
   مشروع يشمل بيانات المشروع والعميل والمعدات والفواتير.
5. **تصدير CSV** — لتصدير كل المشاريع/الفواتير/المعدات إلى ملفات CSV
   (مفيد لفتحها في Excel لأي تحليل إضافي).
6. **نسخ احتياطي بضغطة زر** — نسخ قاعدة البيانات فورًا من الشريط الجانبي.

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

## دعم اللغة العربية في تقارير PDF

مكتبة `reportlab` لا تشكّل الحروف العربية أو تعكس الاتجاه تلقائيًا. للحصول على
نص عربي سليم داخل التقارير:

1. ثبّت الحزمتين الاختياريتين:
   ```bash
   pip install arabic-reshaper python-bidi
   ```
2. حمّل خطًا عربيًا بصيغة `.ttf` يدعم العربية (مثل خط **Amiri** أو
   **Noto Naskh Arabic** من Google Fonts)، وضعه داخل مجلد `fonts/` بجانب
   `app.py` باسم `Arabic.ttf`.

بدون هاتين الخطوتين سيعمل البرنامج بشكل طبيعي، لكن النص العربي داخل ملفات
الـ PDF فقط (وليس واجهة البرنامج) قد يظهر بحروف غير متصلة أو بالاتجاه الخاطئ.

## ملاحظة مهمة حول الترقية من النسخة القديمة

إذا كنت تستخدم النسخة السابقة من البرنامج، فإن قاعدة بياناتها القديمة تحتوي
على حقل "العميل" كنص حر وليس جدولًا مستقلًا. عند أول تشغيل لهذه النسخة، سيكتشف
البرنامج ذلك تلقائيًا، **يأخذ نسخة احتياطية من قاعدة بياناتك القديمة** في نفس
مجلد التطبيق باسم `db_legacy_backup_<تاريخ>.sqlite3`، ثم ينشئ قاعدة بيانات
جديدة فارغة بالبنية المحدثة. بيانات مشاريعك القديمة لن تُفقد (محفوظة في النسخة
الاحتياطية) لكنها لن تظهر تلقائيًا في الواجهة الجديدة — إن احتجت استيرادها،
أخبرني وسأجهز لك سكربت استيراد.

## هيكل الملفات

```
app.py          # الواجهة الرئيسية (PySide6)
database.py     # نماذج قاعدة البيانات (SQLAlchemy) + دوال بحث/إحصائيات
theme.py        # الثيم الداكن (QSS) وألوان الشارات
reports.py      # توليد تقارير PDF (reportlab)
requirements.txt
fonts/          # (اختياري) ضع هنا خط عربي Arabic.ttf لتقارير PDF
```

## أفكار للتوسعة لاحقًا

- تسجيل دخول بكلمة مرور بسيطة إذا شارك أكثر من شخص الجهاز.
- إرسال تنبيهات الفحص عبر البريد الإلكتروني تلقائيًا.
- شاشة عقود/اتفاقيات صيانة سنوية لكل عميل.
- رسم بياني (Chart) للإيرادات الشهرية في لوحة المعلومات.
